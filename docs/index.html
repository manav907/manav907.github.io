Projects

VeeLive

VeeLive is a Unity and C# multiplayer metaverse built for desktop and mobile WebGL, bringing people together in shared online spaces. I built proximity voice with Photon Voice, WebRTC screen sharing, isolated multiplayer rooms, and AWS VPS deployment and CI/CD flows; I also optimized Addressables and textures, cutting runtime memory from about 2.1 GB to 1.02 GB so large environments that had crashed mobile browsers could load.

WebGL performance

Victorian Murder Mystery

Victorian Murder Mystery is a multiplayer among us style game. In this investigation, A stale character preview system left by a bad merge was creating duplicate models, cameras, and lighting setups, dragging the game to about 20 FPS. I used unity profiler and git lens to trace the issue and removed the obsolete system, bringing performance to around 120 FPS.

Read performance article

Mochi the Blob

Mochi the Blob is a mobile vertical platformer built around deliberate, high-stakes jumps. I led its core development from prototype through Google Play release, working across progression, onboarding, backend systems, analytics, monetization, publishing, and live operations.

Shipping and live ops

Gully Champ

Gully Champ is a visual novel and cricket strategy game combining card-based matches with a calendar-driven Yarn story. I built Unity Editor validation for dialogue commands, characters, expressions, sprites, and calendar entries, reducing roughly 700 possible issues to 52 actionable ones; I also fixed a duplicate-dialogue bug caused by a transition regression.

Content validation Duplicate dialogue bug

Tokyo Race Track

Tokyo Race Track is a Unity HDRP proof of concept made for client to showcase Unity's capabilities, that Unity could deliver a dense, high-fidelity racing environment without requiring Unreal Engine. I built and optimized the neon-lit city scene with reflection controls, occlusion culling, and lighting groups so it could be explored, tuned, and recorded.

Read HDRP article

CMAT2

CMAT2 is the successor to a prototype educational game suite, redesigned to support more games and parallel development. I built shared game lifecycles and game-specific level configuration so new games could reuse progression, results, and sync behavior without rebuilding that foundation.

Read architecture article

NumberedTaskbar

NumberedTaskbar is a 28KB Windows utility that displays Win+number shortcut labels over taskbar buttons while the Windows key is held. I built a transparent, click-through native overlay so the mapping is visible at a glance without counting icons or hovering over them.

Building the overlay

FixSteamICON

FixSteamICON repairs blank Steam desktop shortcuts caused by missing local icon files, including after reinstalling Steam while keeping an existing game library. It restores the correct icons from Steam’s data so newly created shortcuts work too, instead of merely replacing icons one by one.
